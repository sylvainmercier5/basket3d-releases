# Basket 3D — téléchargements

APK Android du jeu Basket 3D et fichier `version.json` utilisé par le jeu pour détecter les mises à jour.

## Dernière version

Voir `version.json`. Le fichier APK porte le numéro de version (`basket3d-v0-XX.apk`).
Installation : télécharger l'APK sur le téléphone, l'ouvrir, autoriser l'installation depuis cette source.
